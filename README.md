# Engineering-Portfolio-Project-Sim-Racing-Steering-Wheel
3D-printed sim racing steering wheel built using a hoverboard motor


Sim Racing Steering Wheel Project
Built with a friend as a hands-on hardware project.
Built a functional sim racing steering wheel using a hoverboard motor for rotation.


3D printed all parts of the wheel, including the housing, grips, and mounts.


Wired buttons and paddle shifters by hand and soldered resistors and connections to a controller.


The wheel powered on and ran the program, but smoked due to a short circuit caused by two resistors touching during soldering.


Identified the issue as a wiring and soldering mistake and learned the importance of spacing and insulation.


Next Steps:
Redesigning the bottom to use gears instead of a belt and pulley system.


Planning to make a custom PCB so buttons are built into a cleaner circuit instead of loose wiring.


Will apply circuit design skills learned this semester to improve reliability and safety.


Tools Used:
 3D printing, soldering, resistors, basic electronics, microcontroller programming, CAD.
